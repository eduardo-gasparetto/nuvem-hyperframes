# Requisitos de design para anúncios no Instagram Stories (Meta)

Há cinco posicionamentos diferentes para anúncios no Instagram: Feed, Stories, Explorar, Reels e Pesquisar. Todas as dimensões do feed são compatíveis, mas recomendamos usar uma taxa de proporção de 9:16 para que o conteúdo se ajuste ao formato vertical em tela cheia do Stories. Para Anúncios de Catálogo Advantage+ da Meta (anteriormente conhecidos como anúncios dinâmicos), recomendamos o uso de uma taxa de proporção de 1,91:1.

## Anúncios no Stories
Todas as dimensões de fotos e vídeos do feed (de 1,91:1 a 4:5) agora são compatíveis.

- **Tipo de arquivo:** .mp4 ou .mov (vídeo); .jpg ou .png (foto)
- **Tamanho máximo do arquivo:** 4 GB (vídeo); 30 MB (foto)
- **Duração do vídeo:** máximo 60 minutos; por padrão, as imagens são exibidas por cinco segundos
- **Dimensões:** resolução recomendada 1.080 x 1.920; mínimo 600 x 1.067
- **Codecs compatíveis:** vídeo H.264, VP8; áudio AAC, Vorbis

Safe-zone numbers: none on this page.
