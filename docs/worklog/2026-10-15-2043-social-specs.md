## Decisions + why
- **Scope is graphic design + pipeline only.** Ad strategy and copy (hooks, best-performing length, text limits, hashtags,
  wording policy) are out. Burned-in captions count as visual only; music licensing is a pipeline field (`audio_license`).
- **Meta 9:16 bottom safe zone = 40%** (official, Reels ads with labels) — stricter than the Ads Guide 35%. Proposed universal
  9:16 box: top 14%, bottom 40%, sides 6%, right enlarged for TikTok's action rail.
- **Meta's 20% text rule dropped** — the current official page sets no text-amount limit.
- Each value carries `status` (official / press / third-party / internal) and `verified_at`; unverified values use the conservative side.
- No reliable ready-made dataset exists → build our own JSON.
- Branch created from `session/2026-10-15-motion-identity` (not `main`), because `main` only has the initial commit and the
  `shared/` structure lives on the stacked session branches.
